# 실습과제 1

## 배열명의 의미를 설명하라.
```
배열 첫번째 요소의 주소이다.
```

## 배열표현과 포인터(주소) 표현의 변환 공식을 설명하라
| 구분 | 배열 표현 | 포인터(주소) 표현 |
| --- | --- | --- |
| 배열 요소의 값 | `a[i]` | `*(a + i)` |
| 배열 요소의 주소 | `&a[i]` | `a + i` |
----------

## 배열의 첫번째 요소의 주소만 알면 모든 원소의 주소를 계산할 수있다. 방법을 설명하시오
```
배열은 메모리상에 연속적으로 배치된다.
배열의 첫 번째 요소의 주소와 배열 요소의 자료형을 알면 모든 원소의 주소를 계산할 수 있다.
```

## 배열의 첫번째 요소의 주소만 알면 모든 원소의 값를 계산할 수 있다. 방법을 설명하시오.
```
주소에서 역참조(*)를 사용할 수 있다.
첫 번째 요소의 주소에서 원하는 요소의 위치만큼 이동한 후 간접참조하면 모든 원소의 값을 얻을 수 있다.
```
## 포인터에 대해 가능한 연산의 종류와 의미를 설명하라
### ① 간접참조 연산

```c
*p
```

포인터 `p`가 가리키고 있는 메모리 공간에 저장된 값을 의미한다.

### ② 정수 덧셈

```c
p + n
```

포인터가 현재 가리키는 주소에서 다음만큼 이동한다.

```text
n × 포인터가 가리키는 자료형의 크기
```

### ③ 정수 뺄셈

```c
p - n
```

포인터가 현재 가리키는 주소에서 다음만큼 이전으로 이동한다.

```text
n × 포인터가 가리키는 자료형의 크기
```

### ④ 증가 연산

```c
p++
```

포인터가 다음 요소의 주소로 이동한다.

예를 들어 `int* p`이고 `int`의 크기가 4바이트라면 `p++`을 수행했을 때 주소는 4바이트 증가한다.

### ⑤ 감소 연산

```c
p--
```
포인터가 이전 요소의 주소로 이동한다.

예를 들어 `int* p`이고 `int`의 크기가 4바이트라면 `p--`을 수행했을 때 주소는 4바이트 감소한다.
따라서 포인터의 덧셈이나 뺄셈은 단순히 주소값을 1씩 증가시키거나 감소시키는 것이 아니라 **포인터가 가리키는 자료형의 크기만큼 이동**한다.

## 포인터 연산을 기존의 산술연산과 다르게 정의한 이유는 무엇일까?
```
메모리 단위 접근의 안전성과 편의성때문이다.
```

## 실습과제 3

* a++과 ++a는 순서의 차이가 있다. a++을 출력했을 때 값이 출력되는 게 우선이지만, ++a를 출력할 경우 1을 더하는 것이 우선이 된다.
* 배열의 이름은 증감 연산으로 변경할 수 없기 때문에 a++는 사용할 수 없다. 그렇기 때문에 포인터 변수 p를 선언하여 배열의 시작 주소를 저장하고, *p++를 이용한다.

▼ 소스코드 설명
```
#include <stdio.h>
```
- scanf, printf, 등 여러가지 라이브러리가 들어있는 stdio.h를 포함해라.
```
int main(void)
```
- 메인함수 시작
```
int a[] = { 10, 20, 30 };
```
- a라는 배열을 10, 20, 30으로 초기화
```
int* p = &a;
```
- a의 주소를 p에 저장
```
int i, sum = 0;
```
- i, sum이라는 변수를 선언하고 sum에 0을 저장
```
for (i = 0; i < 3; i++)
  sum += *p++;
```
- 3번 반복
- a의 값을 sum에 더하기
```
printf("sum:%d\n", sum);
```
- 총합 출력
```
return 0;
```
- 0을 반환하고 메인함수 정상 종료

## 실습과제 4

▼ 소스코드 설명
```
#include <stdio.h>
```
- scanf, printf, 등 여러가지 라이브러리가 들어있는 stdio.h를 포함해라.
```
int main(void)
```
- 메인함수 시작
```
double arr[5];
```
- 5개의 방을 가진 실수형 arr 배열 선언
```
double* ptr;
```
- ptr이라는 포인터 선언
```
int i;
```
- i라는 정수형 변수 선언
```
ptr = arr;
```
- arr의 주소를 ptr에 저장
```
for (i = 0; i < 5; i++) {
  printf("실수 입력: ");
  scanf("%lf", ptr++);
}
```
- 5번 반복
- 실수 입력하라는 메시지 출력
- 실수 입력
```
ptr = arr;
```
- arr의 주소를 ptr에 저장
```
for (i = 0; i < 5; i++) {
  *ptr += 2;
  ptr++;
}
```
- 5번 저장
- 입력된 값에 +2
- ptr = ptr + 1;
```
ptr = arr;
```
- arr의 주소를 ptr에 저장
```
printf("\n2씩 증가된 배열의 값:\n");
```
- ptr 값 출력 메시지 출력
```
for (i = 0; i < 5; i++)
  printf("%.2f ", *ptr++);
```
- 5번 반복
- ptr 값 출력
```

```
- 0을 반환하고 메인함수 정상 종료
