# 실습과제 1

## 배열명의 의미를 설명하라.
```
배열 첫번째 요소의 주소이다.
```

## 배열표현과 포인터(주소) 표현의 변환 공식을 설명하라
| 구분 | 배열 표현 | 포인터(주소) 표현 |
| --- | --- | --- |
| 배열 요소의 값 | `a[i]` | `*(a + i)` |
| 배열 요소의 주소 | `&a[i]` | `a + i` |
----------

## 배열의 첫번째 요소의 주소만 알면 모든 원소의 주소를 계산할 수있다. 방법을 설명하시오
```
배열은 메모리상에 연속적으로 배치된다.
배열의 첫 번째 요소의 주소와 배열 요소의 자료형을 알면 모든 원소의 주소를 계산할 수 있다.
```

## 배열의 첫번째 요소의 주소만 알면 모든 원소의 값를 계산할 수 있다. 방법을 설명하시오.
```
주소에서 역참조(*)를 사용할 수 있다.
첫 번째 요소의 주소에서 원하는 요소의 위치만큼 이동한 후 간접참조하면 모든 원소의 값을 얻을 수 있다.
```
## 포인터에 대해 가능한 연산의 종류와 의미를 설명하라
### ① 간접참조 연산

```c
*p
```

포인터 `p`가 가리키고 있는 메모리 공간에 저장된 값을 의미한다.

### ② 정수 덧셈

```c
p + n
```

포인터가 현재 가리키는 주소에서 다음만큼 이동한다.

```text
n × 포인터가 가리키는 자료형의 크기
```

### ③ 정수 뺄셈

```c
p - n
```

포인터가 현재 가리키는 주소에서 다음만큼 이전으로 이동한다.

```text
n × 포인터가 가리키는 자료형의 크기
```

### ④ 증가 연산

```c
p++
```

포인터가 다음 요소의 주소로 이동한다.

예를 들어 `int* p`이고 `int`의 크기가 4바이트라면 `p++`을 수행했을 때 주소는 4바이트 증가한다.

### ⑤ 감소 연산

```c
p--
```
포인터가 이전 요소의 주소로 이동한다.

예를 들어 `int* p`이고 `int`의 크기가 4바이트라면 `p--`을 수행했을 때 주소는 4바이트 감소한다.
따라서 포인터의 덧셈이나 뺄셈은 단순히 주소값을 1씩 증가시키거나 감소시키는 것이 아니라 **포인터가 가리키는 자료형의 크기만큼 이동**한다.

## 포인터 연산을 기존의 산술연산과 다르게 정의한 이유는 무엇일까?
```
메모리 단위 접근의 안전성과 편의성때문이다.
```
