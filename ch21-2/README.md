# 실습과제1
## 표준 입출력 스트림을 접근하는 방법을 설명하라.
```
문자, 문자열 전용 입출력 함수에서 주소를 이용하여 스트림에 접근한다.
```
## 공백을 포함한 문자열을 입력 받을 때 사용가능한 함수는?
```
fgets함수이다.
```
## gets 함수사용시 가장 큰 문제점은 무엇인가?
```
배열의 크기를 초과하는 문자열 입력 시, 오류가 발생한다.
```
## fgets 함수 사용시 문제점은 무엇인가?
```
배열의 크기를 초과하는 문자열 입력 시, 초과한 문자열이
버퍼에 남아 다음 문자열을 입력받을 때 대신 저장된다.
```
## 널문자('\n')와 널포인터(NULL)의 용도를 설명하시오.
```
널문자(\n')는 문자열의 끝을 가리키고, 널포인터(NULL)는 포인터가 아무것도 가리키지 않고 있음을 나타내며 쓰함수가 오류가 생겼을 때 결과가 없다는 뜻으로 널포인터를 반환한다.
```
