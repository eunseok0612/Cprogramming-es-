# 실습과제 1
## 1-1
### 구조체가 필요한 이유를 설명하라.
```
서로 다른 종류(자료형)의 데이터를 모아 하나로 묶어서 다루기 위해 구조체가 필요하다.
```
## 1-2
### 배열과 공통점과 차이점을 설명하라.
```
메모리에 연속적으로 저장된다는 공통점이 있으며,
배열은 같은 종류의 데이터만 모을 수 있으나,
구조체는 서로 다른 종류의 데이터도 모을 수 있다는 차이점이 있다.
```
### 기본자료형과 구조체의 차이를 설명하라.
```
기본 자료형은 하나의 값만 받을 수 있고, 크기가 정해져 있다.
구조체는 여러 개의 멤버 변수로 여러 값을 받을 수 있으며, 크기는 모든 멤버 변수의 크기의 합이다.
```
### 구조체 정의와 구조체 변수 선언의 의미를 각각 설명하라.
```
구조체 정의는 새로운 자료형을 정의하는 일이고,
구조체 변수 선언은 구조체 멤버 변수가 메모리에 할당되는 것이다.
```
