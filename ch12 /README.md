# 실습과제 1
## 1. 16MB 메모리의 주소의 범위를 구하시오.
### 0부터 2^24-1 이므로 0 ~ 16,777,215 이다

## 2. 변수의 주소를 설명하시오.
### 메모리에서 변수가 저장된 위치를 뜻한다.

## 3. 변수의 주소의 자료형은 무엇인가?
### 해당 변수의 자료형 뒤에 *이 붙은 포인터 자료형이다.

## 4. 포인터란 무엇인가?
### 주소를 저장하기 위한 변수(주소형 변수)이다.

## 5. 포인터의 자료형은 무엇인가?\
### 포인터에 저장될 주소의 자료형(자료형*)이다.

## 6. 변수의 주소를 int형 변수에 저장하면 어떻게 되는가?
### 자료형이 일치하지 않아 오류가 발생한다.
